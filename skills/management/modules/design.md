# 设计材料治理

> 本文件是 `design/` 目录的路由文件，被 [SKILL.md](../SKILL.md) 的「design」条目引用。当前为轻量版：定建立时机与边界，目录内部无专门治理制度。

## 建立

开始制作原型图、交互原型或 UI 设计系统时建立 `design/`。

## 边界

**放：** 原型图、交互原型及 UI 设计系统（原型、交互流程、设计系统）。

**不放：** 架构文档、技术文档、普通项目文档、业务源码、运行数据、构建包（文档归 docs/）。

## 演进

本目录在实战中暴露治理缺口（内容混放、顺序违规、验收争议等）时，由用户发起，在本文件中补充该目录的专门治理制度；其余情况不扩写。
