# 网络代理

> 中国大陆访问部分站点和下载源时，可能需要代理。

- 对于提供国内镜像的包管理器，优先使用镜像直连；仅在镜像缺包或故障时，再进入代理探测流程。
- 确需代理时，现场探测本机代理；能用就直接用。代理信息属于会变化的系统配置，必须现场读取，不要写入记忆文件：
  - **候选来源**：环境变量 `http_proxy`、`https_proxy`、`all_proxy`（大小写均检查），全平台通用。
  - **系统代理补充读取**：
    
    - Windows：查注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings` 中的 `ProxyServer`；若为多协议格式，取其中的 HTTP/HTTPS 地址。
    - macOS：运行 `scutil --proxy`。
    - Linux：没有统一位置，环境变量是主要来源。
  - **连通性实测**：配置存在不等于可用，可能是上次代理软件的残留。用候选代理执行：
    
    ```bash
    curl -x <代理地址> -sI --max-time 5 https://www.google.com
    ```
    能拿到响应头且不是 407 才算活代理；407（需要认证）视为不通。若超时，换一个站点再测一次；仍不通再判定为不可用。
  - **失败处理**：探测不到或实测不通时，停止尝试，向用户索要新代理；这比自行更换端口碰运气更高效。用户修复后重新探测。
- 探测全程只读，不修改系统代理设置。
