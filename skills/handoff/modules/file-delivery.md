# 文件路径

> 本模块只处理已经由主 skill 选择的文件路径，不重新判断交付方式，也不执行消息路径。

## 保存

用户明确指定保存目录时，以用户指定为准。否则按以下顺序确定项目根：

1. 优先使用当前环境明确提供的 workspace root，并确认其中的 `AGENTS.md` 是项目根入口。
2. 环境没有提供 workspace root 时，从当前工作目录向上查找 `AGENTS.md`；结合版本库根和入口内容，区分项目根入口、局部入口和适配转发文件，不要简单采用最近的同名文件。
3. 磁盘根、文件系统根、操作系统目录、用户主目录和系统临时目录不算项目根。
4. 无法可靠识别项目根时，询问用户将文件保存到哪里；不得猜测，也不得退回系统临时目录。

确认项目根后：

1. 在项目根创建或复用 `.agents/handoff/`。
2. 文件名使用 `handoff-<YYYYMMDD-HHMMSS>.md`，时间取本机当前时间。
3. 写入前检查重名；冲突时追加短随机后缀，例如 `handoff-20250120-143052-a3f9.md`。
4. 不覆盖已有文件。

## 保存前自查

把交接文件当作唯一可见上下文通读一遍：下一位 Agent 能否说清用户目标、当前真实状态、关键约束、准确下一步和材料位置。缺一项就补齐；发现无依据的事实、失效引用或敏感信息，先修正再保存。

## 回复

保存完成后，只输出交接文件在本机的真实绝对路径，除非用户明确要求预览，不要把交接正文贴到聊天里。
