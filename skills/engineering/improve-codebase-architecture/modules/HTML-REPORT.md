# HTML 报告规范

生成架构报告前读本文件.报告的内容,布局,交互和验收以本文为准;代码结构,数据字段名和具体实现方式自行选择.落点,命名和交付动作按[主 skill](../SKILL.md#2-用-html-报告摆出候选).

需要查看成品效果或复用代码时,再读 [report.html](../assets/report.html).它是可直接打开的参考实现,提供页面骨架,视觉样式和基础交互;也可以独立编写满足本文要求的页面.参考实现与本文不一致时,按本文生成和验收.

## 报告内容

报告列出本轮整理后的全部独立候选,说明架构摩擦,深化方向和预期收益;具体接口设计留到用户选中候选后的追问阶段.

报告信息包括项目名,日期,实际审查范围和可选说明;候选总数,子系统数和推荐等级分布从候选内容计算.演示原型写明来源与日期,虚构内容明确标注.

每个候选包含以下信息.表中的名称说明内容含义,不限定代码里的字段名.

| 信息 | 要写清什么 |
| --- | --- |
| 编号与归属 | 编号如 `C01`,`C17`,同一报告内唯一,筛选和排序后保持不变.归属使用项目现有的子系统或业务域名称. |
| 标题 | 点出深化动作,如「收拢订单接入规则」. |
| 问题与方案 | 各用一句完整的话说清哪里造成摩擦,准备改什么. |
| 推荐等级与依据 | `Strong`(强烈推荐),`Worth exploring`(值得探索),`Speculative`(观望)三选一,用带文字的徽章显示;解释判断依据,不用虚构的分数或工时替代. |
| 依赖类别 | 进程内,本地可替换,端口与适配器,模拟.按[依赖分类](../../codebase-design/modules/DEEPENING.md#依赖分类)判断,不按当前有没有使用 mock 命名. |
| 收益 | 2 至 3 条具体收益,讲清局部性,杠杆效应和测试会怎么改善. |
| 改动范围 | 会波及哪些模块,调用方与契约. |
| 证据与待确认项 | 分开列出支撑判断的位置与现象,以及尚未验证的条件;没有待确认项就明确说明. |
| 涉及文件 | 仓库相对路径,完整展示并允许换行. |
| 前后对比图 | 现状与建议各一张,各带标题,图注和适用的图例,按[图示](#图示)绘制. |
| 相关候选 | 有关联再写,用目标编号链接,标明前置 / 替代 / 关联及理由.前置关系写清方向,互为替代的候选互相链接. |
| ADR 冲突 | 按[主 skill](../SKILL.md#2-用-html-报告摆出候选)判断是否列入.列入后展示 ADR 编号,可访问链接和值得重开的理由,在推荐依据附近醒目标出. |

目录只放足够辨认候选的摘要.详情按编号与归属,标题,问题,方案,推荐依据,前后图,收益,改动范围,证据与待确认项,文件,相关候选的顺序展开;推荐等级和依赖类别跟编号一起显示.

## 页面布局与视觉

采用「全局信息栏 + 左侧完整目录 + 右侧单项详情」,少量候选也沿用这个结构.页面贴满窗口,外层不加边距或圆角框.交互只服务查找与阅读,不扩展成任务看板或批量执行工具.

### 信息栏

顶部固定一行:左侧项目名和数量相邻,右侧日期和圆形的「报告信息」按钮靠右.长标题可以省略显示;窄屏把日期收入报告信息,保持顶栏一行.推荐依据留在各自详情中,不另设「建议先看」区域.

报告信息用浮层展示完整标题,日期,范围,说明和推荐等级分布.浮层限制在视口内,内容过长时内部滚动.展开和收起行为见[报告信息与键盘](#报告信息与键盘).

### 目录与详情

- 左侧按子系统分组,每组显示匹配项数;每项展示编号,标题,推荐等级和一条收益摘要,当前项有清晰的选中样式.
- 筛选区在目录上方,子系统,推荐等级,搜索各占一行,每个控件有可见标签.下方显示匹配数,总数和「清空筛选」.
- 桌面固定左侧筛选区,候选列表独立纵向滚动,溢出时有可辨认的滚动条.右侧详情使用浏览器的页面滚动条.
- 矮窗口放不下筛选区和可用列表时,改为左侧整体滚动.筛选操作保留控件在视野内,不为露出选中项而滚走输入框.
- 窄屏改成目录在上,详情在下,两者在同页可访问.候选列表限高到约半屏并可独立滚动,避免几十项目录把详情推到很远.
- 详情顶部展示当前项在筛选结果中的位置,以及上一项 / 下一项.窄屏可省略位置文字,保留导航.选中候选后直接定位详情,不另设「返回目录」按钮.

### 视觉基准

下面的尺寸和颜色是默认起点,可以为内容长度和窗口做小幅调整;保留信息层次和阅读密度.

| 部位 | 基准 |
| --- | --- |
| 页面尺寸 | 顶栏约 60px 高,窄屏约 56px;桌面目录约 290 至 320px 宽;详情正文最大宽度约 1280px. |
| 字体 | 系统中文无衬线字体;正文 16px,行高约 1.7;项目标题约 18px,详情标题 23 至 29px,目录中的候选标题约 15px;辅助信息 12 至 14px,路径约 13px.中文正常字距,代码标识符保留大小写. |
| 留白 | 详情横向内边距约 24 至 32px,窄屏约 20px;段落和卡片之间保留 16 至 24px 间距. |
| 控件 | 输入框与下拉框约 44px 高,圆角约 14px,箭头与圆角风格协调;信息按钮为圆形,数量为圆角标签. |
| 底色与文字 | 浅底 `#f5f7f5`,白色内容区,细边框 `#dbe3dd`;正文深色 `#233542`,辅助信息灰绿 `#617169`. |
| 强调色 | 绿色 `#1b6d54` 用于选中与主要操作,选中底色浅绿;琥珀色用于探索级建议和 ADR 提示,红色用于图中泄漏.状态同时用文字说明. |

## 浏览交互

### 筛选与选中

子系统,推荐等级和搜索条件取交集.搜索覆盖编号,子系统,标题,问题,方案和文件路径;忽略大小写和首尾空格,空格分开的多个词须全部命中.输入或选择后立即更新结果.

| 操作或状态 | 页面结果 |
| --- | --- |
| 首次打开,链接未指定候选 | 有候选就展示目录第一项;本轮没有候选则说明本次未发现候选,仍可查看报告范围. |
| 筛选后当前项仍匹配 | 保留当前选择和详情. |
| 筛选后当前项被排除 | 选择当前结果第一项,同步更新目录选中样式,详情和地址中的候选编号. |
| 筛选后零结果 | 目录和详情都显示无匹配提示,给出清空入口;清除旧选择和地址中的候选编号. |
| 清空筛选 | 同时重置三个控件,恢复全部候选,再按上面两条非空结果规则确定选择.没有筛选条件时清空按钮不可用. |
| 主动打开不在当前结果内的相关项或历史链接 | 显示指定候选,提示它不在当前结果中,保留当前筛选条件. |

筛选保留输入焦点,数量变化可被读屏获知.筛选导致详情换项时,桌面从详情开头显示,窄屏停在正在操作的筛选区.筛选只替换当前地址,不为每次输入增加一条浏览历史.

### 链接与阅读位置

每项有可直接打开的片段链接,如 `#C17`.目录和相关项都用稳定编号定位.直接打开,刷新或浏览器前进后退后,链接中的编号与详情一致;无效编号显示错误提示和重新从目录选择的指引.

上一项 / 下一项沿当前筛选结果的目录顺序移动,首尾不提供越界操作.当前详情不在结果内时,收起这两个入口.

从目录,相关项或前后项链接进入候选时,从详情开头阅读,焦点移到详情标题,标题不被固定顶栏遮住.再次点击当前项也能回到详情开头.目录保留内部滚动位置,必要时移动到能看见选中项的位置.

同次打开期间,候选切换和浏览器前进后退保留当前筛选条件.刷新只要求按片段链接恢复候选,不要求保存筛选条件.

无片段的报告地址是目录入口,首次打开仍按默认规则展示候选.每次点击目录候选时记住页面位置;浏览器后退回无片段地址时,恢复最近记住的位置并把焦点交回目录,详情可保留当前项.已有候选片段之间的前进后退按候选导航处理.

### 报告信息与键盘

信息按钮可切换浮层的展开与收起.点击浮层内部保持展开;点击外部,键盘焦点移出浮层与按钮所在区域,浏览器窗口失焦,或按 Esc 时收起.Esc 关闭后焦点回到信息按钮.

筛选,目录,详情导航和报告信息都能用键盘操作;焦点有清晰样式,图标按钮有可读名称,滚动目录可通过键盘浏览.焦点的去向按上面的筛选和导航规则处理.

## 图示

每个候选的现状图在上,建议图在下,每张图独占内容区宽度,高度随自己的内容增长.标题区分现状与建议,图注各用一句话说清该图的结论和前后变化.理解建议所必需的信息也要写进正文.

中文图标签在最终显示尺寸下至少 14px.宽图只在图区横向滚动,保持文字可读,不撑宽整页.简单顺序关系可用 HTML 节点和箭头;依赖与时序可用 Mermaid;横截面,体量和嵌套结构可用 SVG.SVG 带 `viewBox`,节点和箭头共用坐标系,图本身作为不执行脚本且不依赖外部资源的静态内容显示.

### 图例与画法

每张图的图例紧邻该图,逐项说明图中用到的边框,填色,线型和箭头.图例含符号,名称和必要说明;符号的形状,颜色,虚实和箭头与图中一致.可按项目扩展含义,不限于模块,接缝,泄漏和深模块,只列该图实际出现的含义.

同类问题沿用同一种画法.同一候选的前后图保持方向,模块名称和颜色含义一致,调用方从同一位置起读.新图默认用实线框表示模块,虚线表示接缝,红色箭头表示泄漏,深色粗框表示深模块,灰色实线箭头表示普通调用.复用历史图时,按原图的实际画法写图例.

- **调用与依赖**:用流程图,往返次数用时序图.泄漏标在连线上,节点红框不能代替;使用 Mermaid `linkStyle` 时,增删连线后核对编号.
- **横截面**:前图画出浅模块逐个转发,后图画出合并后的职责.每条的高度按文字确定.
- **体量图**:分别画接口和实现,表达接口收窄,实现收纳复杂度.注明「概念示意」,不把矩形面积当成代码量或实测数据.
- **调用图坍缩**:前图用嵌套盒子展示调用树,后图收进一个模块,内部调用用次要文字表示.

图复杂到需要长段解释时,先缩小图的范围.需要 Mermaid 配置或语法时查[主题](https://mermaid.js.org/config/theming.html)和[流程图](https://mermaid.js.org/syntax/flowchart.html).

### 渲染与失败

只渲染当前候选的图,本次打开期间复用已生成的结果.快速切换候选后,旧的异步结果只能丢弃或缓存,不能覆盖新详情.

图加载或语法失败时显示失败提示,保留图注和文字分析,目录与筛选继续可用.交付前修复失败的图;网络不可用时可改成内联 HTML 或 SVG,交付页面应展示成图.

## 文件与实现

报告交付为单个 HTML 文件,数据,布局样式和基础交互都在文件内,本地直接打开即可使用.采用内联 CSS 和 JavaScript,无需后端或外部样式框架;绘图库可按需外载,断网后的行为按上一节处理.页面数据无法读取时给出明确提示,避免空白页;禁用 JavaScript 时说明需要启用才能使用交互.

项目文字按文本展示,其中的 HTML 或脚本片段不执行.嵌入 JSON 时先正常序列化,再把结果中的 `<` 替换为 JSON 转义序列 `\u003c`(一个反斜杠),避免 `</script>` 提前关闭数据区.项目文字不拼进可执行脚本;引用链接使用 `http:`,`https:`,`file:`,相对路径或页内片段,不接受可执行脚本的地址.

**复用参考实现时**:复制 [report.html](../assets/report.html),按其中 `script#report-data` 的样例结构替换全部虚构内容,保留已满足规范的布局与交互.内部字段和图数据格式从该实现读取.

## 交付验收

每份报告都实际打开,按下表验收真实内容和可触发的交互,每张图都检查.没有相关候选就跳过相关项跳转检查;外载绘图库才检查加载失败,异步绘图才检查旧结果覆盖.其余场景按本次候选内容执行,补充数据验证的范围见表后说明.

| 场景与操作 | 通过条件 |
| --- | --- |
| 核对报告与候选 | 数量及分布与内容一致,编号唯一,每项内容完整,目录和相关项指向存在的候选,演示来源可辨认. |
| 组合筛选,多词搜索,清空 | 编号,标题和文件路径都能查到;匹配数准确,选中,详情和地址按筛选规则同步;当前项仍匹配就保留,零结果不残留旧详情,输入焦点与控件保持可见. |
| 从目录和相关项切换,使用前后项,再次点击当前项 | 对应候选从头显示,目录选中样式与位置正确;前后项只走当前结果,主动跳出筛选仍保留条件并提示. |
| 直接打开链接,刷新,前进后退,打开无效编号 | 编号与详情一致;同次打开保留筛选,后退到无片段的目录入口恢复位置;无效编号给出明确指引. |
| 打开报告信息,点击内部与外部,Tab 移出,按 Esc | 内部点击保留展开,其它关闭行为符合规定,Esc 后焦点回按钮;长说明可读到末尾. |
| 宽屏,窄屏,矮窗口;键盘浏览靠下的候选 | 顶栏一行,全部控件与候选可达,滚动范围正确,焦点可见,输入框不会被滚走;长标题,路径和宽图不撑宽整页. |
| 逐图检查,快速切换,模拟绘图库加载失败 | 图中文字可读,图例与真实画法一致,没有旧图覆盖新详情;失败有提示且文字与浏览功能可用. |
| 查看本轮零候选与筛选零结果 | 两种原因分别说明;前者可查看报告范围,后者可清空筛选继续浏览. |

新写或修改页面实现时,另用少量,几十项和零候选的虚构数据覆盖表中适用场景,包括真实数据未触发的空状态,相关项和长内容.至少覆盖约 1440px 宽屏,320px 窄屏和约 400px 高的桌面窗口.验证数据与真实报告分开,标明虚构用途.原样复用参考实现时,完成本次真实报告的验收即可,无需另造这些数据.

## 措辞

架构概念按 [codebase-design 术语表](../../codebase-design/SKILL.md#一术语表)命名,同一概念始终用同一名称.这个要求约束概念名,普通动词和解释用自然中文;遇到表中未覆盖的概念,先说明含义,已有概念沿用原名.

直接写结论和理由,例如「订单接入模块是浅的:接口几乎跟实现一样大」「定价逻辑从接缝处泄漏」.收益写清调用,修改和测试会怎样变化,如「局部性:日志路径统一在日志模块维护」「接口收窄:调用方只传消息,路径解析留在实现里」.
