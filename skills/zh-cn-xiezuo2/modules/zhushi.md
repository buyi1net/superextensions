# 代码注释

> 本模块取得代码注释任务的场景所有权，只补注释语言、源码编码和载体保护制度。何时写注释、写什么注释属于工程判断，由项目开发规范负责。

## 语言

注释（行注释、块注释、文档注释、docstring）默认使用简体中文；改已有英文注释时一并改中文，除非用户、项目或工具链要求其它语言，或保留外部协议原文更必要。

## 翻译分流

- 把外文注释译成中文时，额外完整读取并执行 [外文译中文](./fanyi.md)，再执行本模块的语言和编码制度。
- 把中文注释译成外语时，额外完整读取并执行 [对外表达](./duiwai.md)，再执行本模块的编码制度。
- 只翻译用户指定的注释内容；周围源码、代码标识和格式保持原样。

## 编码

- 新建源文件使用 UTF-8；修改已有文件时跟随原编码，不擅自转换，避免整文件 diff 或破坏已有非 ASCII 字符。
- 工具链只支持 ASCII、Latin-1、Shift-JIS 等编码时，注释退回工具链支持的语言，不为中文注释引入编译或构建故障。
- MSVC 或 Visual Studio 编译 C/C++ 时，不带 BOM 的 UTF-8 源文件可能按系统代码页解析中文并触发 C4819 或乱码。使用 UTF-8 BOM，或给编译器添加 `/utf-8`。

## 示例

```c
// 按设备实际返回的通道数动态分配缓冲区
int channels = device_get_channel_count(dev);
```

不要写成半中半英的注释：

```c
// alloc buffer for 每个 channel
```
