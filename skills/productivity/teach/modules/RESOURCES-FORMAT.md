# RESOURCES.md 格式

`RESOURCES.md`：精选的可信资源清单，涵盖这个话题的核心来源。课程里讲的知识点要从这里取，不要靠模型的预训练知识瞎猜。见识则来自这里列出的社区。

## 结构

```md
# {话题} 资源清单

## 知识

- [书籍：《力量训练的科学与实践》Zatsiorsky & Kraemer 著](https://example.com)
  关于训练安排与适应机制的经典著作。适用场景：周期安排、恢复、强度区间等任何相关问题。
- [文章：「我该练多少？」by Greg Nuckols（Stronger By Science）](https://example.com)
  基于实证的训练量参考综述。适用场景：确定每个肌群的每周组数目标。

## 见识（社区）

- [r/weightroom](https://reddit.com/r/weightroom)
  质量较高的 subreddit，管理严格，拒绝伪科学。适用场景：训练计划点评、平台期排查。
- 线下：{健身房名称} 周二力量课
  适用场景：动作的实时教练反馈。
```

## 规则

- **只认高可信度来源。** 优先采信一手资料、业界公认的专家、同行评审的成果，以及管理严格的社区。凡是打着教育旗号做营销的，一概不取。
- **每一条都要写注释。** 光秃秃一个链接，三个月后就没用了。加一句话说明：这条讲什么，什么时候该用它。
- **按「知识/见识」分组。** 呼应  [SKILL.md](../SKILL.md) 里的理念。一条资源只归入其中一组即可。
- **有空白就明说。** 如果学习目标所需要的某个领域找不到好资源，就单列一个 `## 缺失` 章节，写清楚缺什么，以便后续定向寻找。
- **大胆删减。** 发现某条资源不靠谱、太浅薄或偏离了学习目标，就直接删掉，不要留着。五条精的胜过三十条水的。
- **记录社区偏好。** 如果学生明确表示不想加入任何社区，就在这里记一笔，免得后面每次都要再提。
