# 学习记录格式

学习记录存放在 `./learning-records/` 下，按顺序编号：`0001-短横线命名.md`、`0002-短横线命名.md`，以此类推。目录懒加载，写第一条记录时再创建。

它相当于教学领域的 ADR：记录那些不那么显而易见的收获、关键心得，以及学生明确说过的已有基础。这些记录用来推算学生的最近发展区。

## 模板

```md
# {学会了什么的短标题}

{用一到三句话说明：学到了什么（或之前已掌握了什么），以及这件事对后续课程为什么重要。}
```

格式就这么简单。一条学习记录可以只有一段话。它的价值在于记下「这个现在已经会了」以及「这会让接下来的教学发生什么变化」，而不是填表格。

## 可选字段

只有确实有用才加。大多数记录用不上这些：

- **Status** 头注（`active | superseded by LR-NNNN`）：当之前的某条学习记录被新认识推翻时，用它来标记旧记录的状态。
- **Evidence**：学生如何展现出这个理解（答对了一个问题、完成了一项练习、提到过相关经历）。当以后可能需要回头核实这条记录时值得写上。
- **Implications**：学完这个之后，接下来能做什么、不用再做什么了。如果这个影响不是一眼就能看出来的，才值得记一笔。

## 编号规则

扫描 `./learning-records/`，找到当前最大的编号，加一。

## 什么时候该写学习记录

满足以下任意一条就写：

1. **学生对某个不简单的东西展现出了真正的理解**：不是「听过」，而是有证据能正确地用出来。这意味着教学的下限提高了。
2. **学生透露了已有基础**：「我已经会 X 了。」记下来，免得后面重复教。顺便记一下对方自称的掌握程度。
3. **纠正了一个误解**：学生之前信了某个错误的东西，现在明白了错在哪。这类记录价值很高，往往能预测相关话题上将来可能再绊倒的地方。
4. **学习目标因为学习本身而发生了变化**：学生发现自己真正在意的和起初想的不一样。关联到 [[MISSION.md]] 并同步更新。

### 什么情况不该写

- 只是课上讲过的内容。讲过不等于学会，要等证据。
- 已经在 [[GLOSSARY.md]] 词汇表里作为术语定义记过的内容，不要重复写。
- 每次会话的活动日志。学习记录不是日记，它记录的是能影响决策的关键信息。

## 取代旧记录

当后写的记录推翻之前的某条记录时（学生的理解深化了、或者修正了），在旧记录上标 `Status: superseded by LR-NNNN`，不要直接删掉。理解演进的轨迹本身也是有价值的参考信号。
