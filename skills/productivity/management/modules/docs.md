# 文档目录治理

> 本文件是 `docs/` 目录的路由文件，被 [SKILL.md](../SKILL.md) 的「docs」条目引用。当前为轻量版：定建立时机与边界，目录内部无专门治理制度。

## 建立

写下第一份要长期保留的说明时建立 `docs/`（写完就扔的草稿放 temp/，不算 docs）。

## 边界

**放：** 项目全部长期维护的使用、技术、架构、决策、计划和交付文档。

**不放：** 视觉设计源文件、业务源码、参考项目副本、临时报告（临时报告放 temp/）。

## 演进

本目录在实战中暴露治理缺口（内容混放、顺序违规、验收争议等）时，由用户发起，在本文件中补充该目录的专门治理制度；其余情况不扩写。
