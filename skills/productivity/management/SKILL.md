# 项目管理

> 全程红线：治理先于内容。先读取项目现有入口并判断工作模式，再决定使用项目内规则还是本 skill 的建设规范；不得先创建、下载、生成、修改、移动或运行主体内容，最后再补治理。

## 目录判定通则

- 本索引用于任何项目，不限开发场景：命中场景条目的按条目执行；不命中的不强行套用，项目按自己的内容形态建立自定义目录，并在根入口登记职责；
- 目录跟随内容出现而建立，不预建空目录；
- 拿不准内容归属时，先判断删了能不能重新产生：能 → `temp/`；不能 → 按内容性质归场景目录或自定义目录；判断不了先问用户，不得先写入再整理；
- 目录命名语言按项目场景分三层：①有英文工具链（cargo、npm、GitHub 等）或对外发布的场景，一级目录用英文，二级及以下跟随内容语言（母语内容用母语目录）——层级的服务对象不同，语言混排不怪；②纯母语业务场景，全部母语（如「证据材料/」优于「evidence/」）；③设计、视频、PDF 处理等专业场景，目录名跟随该行业软件和从业习惯（如「素材/成稿/工程/成片」），不强翻英文也不硬套开发目录名；同一项目内风格保持一致；
- **宿主优先**：条目目录名只在「该内容是项目主线」时作为一级目录建立（主线以项目根 README.md 的项目定义为准）；内容不是项目主线时，降为二级目录挂进宿主场景目录下（如开发项目里的宣传视频挂 `design/`，设计项目里的工具脚本挂项目自定义目录）；防止交叉内容把项目一级目录搅乱；
- **落点红线：** 绝对不得在用户不知情的情况下在项目目录外创建文件。凡为当前项目产生的内容（调研、下载、实验、构建、测试、输出、备份，无论是否临时、是否提交版本控制），落点必须在项目根内；确需项目外的（备份给用户随手可取、跨项目共享、工具强制、用户指定），必须先询问用户并取得同意，记录准确路径、用途和清理方式；系统临时目录和当前工作目录都不是默认落点；写入前先确认路径在项目根内，不得先生成再搬运；
- **工具重定向义务：** 工具默认输出到系统临时目录或项目外时，先尝试重定向（工作目录、输出参数、TMPDIR/TEMP 环境变量、工具配置）；确实无法重定向的，按落点红线的询问流程处理，例外不是默认；
- **变更联动：** 内容新增、移除或职责变更后，同一次提交里同步更新所有登记它的位置（README.md 索引、`AGENTS.md` 路由、对外清单）；收尾自查：本次改动影响的内容，其登记处是否已同步——不得改了内容留着旧索引；
- 每个承载内容的一级目录建立时，同步建立入口文件（规则见 [Agent 入口治理](./modules/agent-entry.md)）；
- `target/`、`node_modules/`、`dist/` 等工具链生成目录不在本索引内，由工具自动创建并纳入忽略规则，不手工维护。

## 内容与场景索引

> 全程红线：不分阶段，看意思不看词。必须逐条检查下列触发条件。

### Agent入口

**触发与强制措施：** 凡任务涉及 `AGENTS.md`、`CLAUDE.md` 中任意一个文件的创建、迁移、修改、移动、重命名或验收，必须在处理其中任意一个文件前完整读取并执行 [Agent 入口治理](./modules/agent-entry.md)。

### 说明文件

**触发与强制措施：** 凡任务涉及 `README.md` 的创建、修改、重命名、迁移或验收，无论项目根、一级目录还是发布区，必须在动笔前完整读取并执行 [README 治理](./modules/readmes.md)；写什么、不写什么、以该文件为准。

### 创作素材 - assets

**触发与强制措施：** 凡任务涉及设计参考图、视频原始素材、待处理文档、录音、拍摄底片、扫描件或其它不可再生的创作原始输入的收集、导入、拍摄、扫描、下载、整理或验收，必须在判断内容归属、确定存放位置或开始处理前认定为素材场景，按 [创作素材治理](./modules/assets.md) 执行。不得因素材暂时由程序生成就误归临时内容。散件素材（图片、音频、视频片段、单个文档）归本场景；完整外部仓库或成套外部项目副本按「外部材料 - reference」条目执行。

### 历史归档 - archive

**触发与强制措施：** 凡任务涉及让旧版本、旧方案或阶段成果退出当前流程但继续保留，或者对已有归档内容进行迁移、压缩、索引、恢复、清理、引用或验收，必须在确定归档位置或开始处理前认定为归档场景，按 [归档目录治理](./modules/archive.md) 执行。创作内的轮次更替（第 2 稿换第 5 稿）留在过程稿目录做版本管理，不算归档；整作品定版后的历史版本才进归档。

### 原型设计 - design

**触发与强制措施：** 凡任务涉及 UI 原型、交互原型、UI 设计系统、设计令牌、组件规范或原型验证资料的创建、修改、分类、移动或验收，必须在确定材料位置或开始处理前认定为设计场景，按 [设计材料治理](./modules/design.md) 执行。平面设计、视频、文档处理等创作内容不走本条目，按素材/过程稿/成品条目执行。

### 产物交付 - delivery

**触发与强制措施：** 凡任务涉及准备、组装、验证、转正、移出旧版本或整理最终交付物（发布包、压缩包、安装包、插件包、镜像清单、设计定稿包、成片等），或建立、维护、审计交付目录，必须在组装或写入前完整读取并执行 [交付目录治理](./modules/delivery.md)；交付物必须经暂存验证后整体转入 `delivery/`，禁止在交付目录内直接开发或修补。

### 项目文档 - docs

**触发与强制措施：** 凡任务涉及使用说明、技术说明、架构说明、决策、计划、交付说明、运维说明或其它长期项目文档的创建、修改、分类、移动、重命名、索引、交接或验收，必须在确定文档位置或开始处理前认定为文档场景，按 [文档目录治理](./modules/docs.md) 执行。

### 过程稿件 - drafts

**触发与强制措施：** 凡任务涉及设计初稿、剪辑工程、多轮修订稿、工程文件、模板、半成品或其它需要保留的创作中间态的创建、迭代、版本切换、导出、整理或验收，必须在判断内容归属、确定存放位置或开始处理前认定为过程稿场景，按 [过程稿件治理](./modules/drafts.md) 执行。不得因未定稿就误归临时内容。

### 外部材料 - reference

**触发与强制措施：** 凡要把外部项目、文档、标准、网页、数据、模板、素材、样例、网址或来源记录放入项目，或者整理、维护项目内已有的外部材料，必须在判断内容归属、确定存放位置或开始处理前认定为参考场景；建设、修复，或治理模式确认需要调整本场景时，完整读取并执行[参考材料治理](./modules/reference.md)。不得因只保留外部链接、尚未取得本地副本或准备把材料作为正式输入而跳过归属判断。

### 创作成品 - outputs

**触发与强制措施：** 凡任务涉及设计定稿、成片、处理完成的文档、导出的最终版本或其它已定稿创作产出的定稿、导出、多格式生成、交接、整理或验收，必须在判断内容归属、确定存放位置或开始处理前认定为成品场景，按 [创作成品治理](./modules/outputs.md) 执行。成品外发分三种：项目内定稿不外发留本目录；过程性外发（审核版、确认版，还会再改）从本目录直接发，不进交付流程；正式交付（定版、要版本管理和可追溯）按「产物交付 - delivery」条目转正。

### 项目测试 - tests

**触发与强制措施：** 凡任务涉及跨子项目、跨模块、真实服务、真实接口、端到端流程、回归或交付验收的测试、测试数据和测试产物，必须在确定测试位置或开始创建、修改、分类、移动、运行、交付、清理或验收前认定为项目测试场景，按 [测试目录治理](./modules/tests.md) 执行。

### 执行脚本 - scripts

**触发与强制措施：** 凡任务涉及准备重复执行的构建、测试、部署、迁移、校验、同步、转换、导出或数据处理操作，或者相关脚本的创建、修改、分类、移动、执行、交接或验收，必须在确定脚本位置或开始处理前认定为脚本场景，按 [脚本目录治理](./modules/scripts.md) 执行。

### 核心源码 - source

**触发与强制措施：** 凡任务涉及业务代码、可维护技术包、独立交付单元或单元测试的读取、创建、修改、移动、重命名、拆分、测试、交付或验收，必须在确定源码位置或开始处理前认定为源码场景，按 [源码目录治理](./modules/source.md) 执行。

### 临时文件 - temp

**触发与强制措施：** 凡任务涉及程序运行产生的数据、日志、截图、缓存、中间文件、下载物、实验文件、一次性脚本、运行副本或 Agent 工作文件的创建、生成、暂存、复制、移动、清理或验收，必须在判断内容归属、确定存放位置或开始处理前认定为临时内容场景，按 [临时目录治理](./modules/temp.md) 执行。需要保留的中间态（初稿、剪辑工程、修订稿）不归临时内容，按「过程稿件 - drafts」条目执行。

### 源数据 - data

**触发与强制措施：** 凡任务涉及源数据、快照、证据、采集数据、导入备份或其它不可再生事实材料的产生、取得、导入、快照、备份、引用、迁移或验收，必须在判断内容归属、确定存放位置或开始处理前认定为源数据场景，按 [源数据目录治理](./modules/data.md) 执行。不得因内容暂时由程序生成就误归临时内容。服务流程与事实记录的（快照、证据、备份）归本场景；作为创作加工原料被消费的（待剪辑素材、待处理文档）按「创作素材 - assets」条目执行。
