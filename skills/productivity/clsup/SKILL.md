# 任务收尾清理

> 本 skill 仅由用户手动调用.任务告一段落时运行,负责打扫现场,清除执行过程中遗留的各类临时文件与中间产物.

## 职责边界

- **全场景通用打扫**:不论是写代码,做调研,写文案,整理表格还是跑命令行,只要是任务过程中产生的一次性中间物,统统扫除.
- **保护核心成果**:本次任务的最终交付物(正规文档,交付表格,源码,配置,定稿资产等)原样保留.
- **全域排查**:排查当前目录及子目录,清空 `temp/` 临时区,核对是否有工具在外部(如系统临时目录,下载目录)遗留了未清理的运行副本.

## 清理步骤

### 1. 扫描工作区现场

根据当前目录是否处于版本控制,选择对应的扫描手段:

- **有 Git 环境**:

  ```bash
  git status -uall
  ```

  直接检视所有未跟踪文件和未提交变更.

- **无 Git 环境(普通文件夹/日常办公目录)**:
  列出最近修改或新建的文件(重点核对今天或本次会话时间段生成的内容):

  - Linux/macOS: `ls -laht` 或 `find . -maxdepth 2 -mmin -120`
  - Windows: `dir /od` 或 PowerShell 查看近期变更文件.

### 2. 识别三类常见临时残留

不管什么任务,模型产生的垃圾文件基本逃不出这三类:

1. **日常任务类残留**:
   - 网页/接口临时下载的未整理文件(如 `tmp_*.html`,`*.download`,`dump.json`).
   - 临时转换产生的文件(如文档转换过程中的 `.pdf.tmp`,`~*.docx`,`extracted_*/`).
   - 临时截图,截屏缓存或爬取的数据切片.
2. **开发与脚本类残留**:
   - 一次性探针与测试脚本(如 `test.*`,`temp.*`,`run.*`,`scratch.*`).
   - 运行日志与堆栈导出(如 `*.log`,`*.out`,`err.txt`).
   - 本地运行时缓存(如 `__pycache__`,`.pytest_cache`,`.tmp`).
3. **临时工作区与会话残留**:
   - `temp/` 目录下的所有临时工作文件与运行副本.
   - 本会话启动的临时子代理或临时工具产生的中间落盘物.

### 3. 分类与核实

将所有现场变动划入两份清单:

- **待清理清单**:确认是一次性中间产物,临时抓取/导出,探针脚本或无用缓存.
- **正式保留清单**:属于老大本次任务明确要求产出的正文,成果文件或业务改动.

> **存疑处理**:凡无法一眼判断是否为有效劳动成果的文件(例如写了一半的分析大纲,未整理完的素材表),先向老大说明并在清单中单独提示,不擅自删除.

### 4. 执行删除

- 使用环境原生命令直接删除待清理清单中的文件.
- `temp/` 目录若已无任何需保留物,按轻量治理原则整体清空.
- 外部临时目录(如系统临时路径下)若有本次会话产生且已无用的文件,同步清理.

### 5. 闸门验收

**完成标准**:

1. 工作区(或目录)中不再残留任何本次任务产生的临时探针,下载抓包,中间转换物和日志文件.
2. 仅保留本次任务明确要求的最终成果或修改.
3. 输出一份极简的打扫清单:删除了哪些临时垃圾,保留了哪些成果.
