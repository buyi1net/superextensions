# 中英工程术语表（中文 → 英文方向）

> 管中文译英文时的反向陷阱：一个中文工程词对应多个英文表达，选错就变了意思。只收实际交流中证明会翻错的词；判定不出来的按"待确认"处理。

| 中文 | 可能译法 | 区别 |
|---|---|---|
| 需求 | requirement / request / issue | 正式规格、用户请求、问题单，含义不同 |
| 上线 | release / deploy / go live | 发布版本、部署系统、正式启用 |
| 适配 | support / integrate / make compatible | 不要一律翻成 adapt |
| 复现 | reproduce | bug 语境固定用词 |
| 回归 | regression | 测试语境是 regression test，不是 return |
| 兜底 | fallback | 不是 guarantee 也不是 bottom |
| 方案 | approach / proposal / design | 按完成阶段选：思路、提案、定稿设计 |
| 同步一下 | update / share / sync | 口语多为"告知/对齐信息"，不一定是 synchronize |
| 联调 | integration testing / joint debugging | 按语境 |
| 灰度发布 | staged rollout / canary release | 按发布策略 |
| 重构 | refactor | 固定用词，不是 rebuild/restructure |
| 踩坑 | pitfall / gotcha | 名词化时 |
| 报错 | error message / throw | 看是消息还是动作 |
| 兼容 | compatible / backward compatible | 版本方向要写明 |
| 封装 | encapsulation / wrap | 面向对象用前者，包一层用后者 |
| 性能优化 | optimize / tune | 系统级用 optimize，参数级用 tune |
